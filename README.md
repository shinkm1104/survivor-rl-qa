# Survivor RL QA

강화학습 에이전트가 서바이벌 게임을 직접 플레이하고, 그 결과로 게임을 자동 QA하는 것을 목표로 하는 프로젝트입니다. 게임은 Unity로 만들었습니다.

> **현재 상태:** 게임 구현까지 완료했습니다. 강화학습은 아래 [구현 계획](#구현-계획) 순서대로 진행합니다.

## 바로 해보기

1. [Releases](https://github.com/shinkm1104/survivor-rl-qa/releases/latest)에서 ZIP 파일을 받습니다.
2. 압축을 풀고 `SurvivorLab.exe`를 실행합니다.

압축을 푼 폴더 안의 파일은 다른 곳으로 옮기지 말고 그대로 두세요. exe 파일만 따로 꺼내면 실행되지 않습니다. 지금은 Windows 64비트만 지원합니다.

## 조작

| 키 | 하는 일 |
|---|---|
| WASD 또는 방향키 | 이동 (공격은 자동) |
| 1, 2, 3 또는 마우스 클릭 | 레벨업 보상 고르기 |
| Space | 일시 정지 / 다시 시작 |
| Esc | 메뉴로 |

다른 창을 누르면 게임이 멈춥니다. 돌아와서 Space를 누르면 이어서 할 수 있습니다.

## 공격 방식

시작할 때 마법사 네 명 중 하나를 고릅니다. 마법사마다 공격 방식이 다릅니다.

| 마법사 | 공격 |
|---|---|
| 마탄술사 | 기본 마법사입니다. 가장 가까운 적에게 자동으로 마법탄을 쏩니다 |
| 파동술사 | 주위에 동그란 파동을 퍼뜨려 적을 쓰러뜨립니다 |
| 바위술사 | 지나간 자리에 바위를 남기고, 바위에 닿은 적이 피해를 입습니다 |
| 박수술사 | 보는 방향 쪽으로 박수를 칩니다 |

## 게임 방법

적을 쓰러뜨리면 파란 구슬(경험치)이 떨어집니다. 구슬을 모아 레벨이 오르면 강화 카드 3장 중 하나를 고릅니다.

- 레벨 7과 14에는 공격에 속성을 붙입니다. 화염, 번개, 산성, 냉기, 암흑 중에서 고르고, 같은 속성을 두 번 고르거나 서로 다른 속성을 섞을 수 있습니다.
- 1분마다 특수 효과가 있는 두루마리를 하나 고릅니다. (최대 2개)
- 30초마다 웨이브가 바뀌면서 적이 많아지고, 빨라지고, 단단해집니다. 박쥐는 빠른 적이고, 유령은 줄지어 맵을 쓸고 지나갑니다. 유령 줄에는 빈틈이 하나 있습니다.
- 최대한 오래 버티는 게 목표입니다. 마법사별 최고 생존 기록이 저장되고, 30분을 버티면 그 판은 생존 성공으로 끝납니다.

## 구현 계획

같은 게임, 같은 평가 기준에서 알고리즘을 하나씩 쌓아 가며 성능을 비교합니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 게임 구현: 전투, 레벨업, 속성, 두루마리, 웨이브, 규칙 테스트 | 완료 |
| 1 | RL 환경 만들기: 헤드리스 실행(화면 없이 빠르게 돌리기), 관측·행동·보상 정의, 비교용 봇, 평가 루프 | 예정 |
| 2 | 표 기반 Q-learning: 이동 정책 | 예정 |
| 3 | DQN: 신경망으로 이동 정책 확장 | 예정 |
| 4 | REINFORCE: 레벨업 카드 선택 정책 | 예정 |
| 5 | PPO (Unity ML-Agents): 이동과 카드 선택을 함께 학습 | 예정 |
| 6 | 자동 QA: 이상 상태 감시, 실패 재현, 밸런스 리포트, 수치 변경 회귀 검사 | 예정 |
| 7 | 최신 논문 기법 구현 및 비교 | 목표 |

## 직접 빌드하기

필요한 것은 Unity **6000.0.74f1**과 Windows Build Support 모듈입니다. Unity Hub에서 설치하세요.

```bat
open-unity.cmd      :: Unity 에디터로 프로젝트 열기
build.cmd --verify  :: 게임 규칙 테스트만 실행
build.cmd           :: Builds\Windows 에 실행 파일 만들기
play.cmd            :: 빌드한 게임 실행
```

Unity를 다른 경로에 설치했다면 `UNITY_EDITOR` 환경 변수에 `Unity.exe`의 전체 경로를 넣어주세요. 빌드할 때마다 게임 규칙 테스트가 먼저 돌고, 로그는 `Logs/build.log`에 남습니다.
