# Survivor RL QA

강화학습 에이전트가 서바이벌 게임을 직접 플레이하고, 그 결과로 게임을 자동 QA하는 것을 목표로 하는 프로젝트입니다. 같은 게임 위에서 Q-learning부터 PPO, 최신 논문 기법까지 알고리즘을 하나씩 쌓아 가며 비교합니다.

> **현재 상태:** 게임 구현 완료, 1단계(RL 환경) 설계 완료. 아래 [구현 계획](#구현-계획) 순서대로 진행합니다.

![플레이 미리보기](docs/media/gameplay.gif)

## 구현 계획

같은 게임, 같은 평가 기준에서 알고리즘을 하나씩 쌓아 가며 성능을 비교합니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 0 | 게임 구현: 전투, 레벨업, 속성, 두루마리, 웨이브, 규칙 테스트 | 완료 |
| 1 | RL 환경 만들기: 헤드리스 실행(화면 없이 빠르게 돌리기), 관측·행동·보상 정의, 비교용 봇, 평가 루프 | 설계 완료 ([설계 문서](docs/rl/01-environment.md)) |
| 2 | 표 기반 Q-learning: 이동 정책 | 예정 |
| 3 | DQN: 신경망으로 이동 정책 확장 | 예정 |
| 4 | REINFORCE: 레벨업 카드 선택 정책 | 예정 |
| 5 | PPO (Unity ML-Agents): 이동과 카드 선택을 함께 학습 | 예정 |
| 6 | 자동 QA: 이상 상태 감시, 실패 재현, 밸런스 리포트, 수치 변경 회귀 검사 | 예정 |
| 7 | 최신 논문 기법 구현 및 비교 | 목표 |

### 공통 학습 설정

모든 단계가 아래 조건을 똑같이 씁니다. 자세한 내용과 각 값을 고른 이유는 [1단계 설계 문서](docs/rl/01-environment.md)에 있습니다.

| 항목 | 값 |
|---|---|
| 구조 | Python에서 학습, Unity(ML-Agents)는 환경만 담당, 헤드리스 실행 |
| 판단 주기 | 0.1초 (게임 2틱) |
| 판 길이 | 학습·평가 모두 5분(3,000 step)으로 시작. 게임 규칙의 최대 30분은 그대로 |
| 관측 | 연속값 30개 (가까운 적 8마리, 플레이어 위치·체력, 경험치 구슬, 경과 시간). 표 기반 Q-learning은 648개 상태로 나눠 씀 |
| 행동 | 정지 + 8방향 이동 (공격은 자동) |
| 보상 | 생존 +0.01/step, 사망 −1 |
| 할인율 γ | 0.99 |
| 평가 | 마법사당 평가 시드 40판, 비교용 봇 4개(정지·무작위·도주·회피+사냥)와 비교 |

| 단계 | 알고리즘 | 주요 시작 설정 |
|---|---|---|
| 2 | Q-learning | α 0.1, ε 1.0→0.05, 마법사당 2,000판 |
| 3 | DQN | Adam 1e-4, 버퍼 100k, 배치 64, 타깃 갱신 1,000 step, 2×128 신경망 |
| 4 | REINFORCE | Adam 1e-3, 이동 평균 기준선, 2×64 신경망 |
| 5 | PPO | 학습률 3e-4, clip 0.2, GAE λ 0.95, 엔트로피 5e-3, 2×128 신경망 |

## 게임

마법사 네 명 중 하나를 골라 몰려오는 적을 버티는 서바이벌 게임입니다. 이동만 조작하고 공격은 자동입니다.

| 마법사 | 공격 |
|---|---|
| 마탄술사 | 가장 가까운 적에게 마법탄을 쏩니다 (기본) |
| 파동술사 | 주위에 동그란 파동을 퍼뜨립니다 |
| 바위술사 | 지나간 자리에 바위를 남기고, 닿은 적이 피해를 입습니다 |
| 박수술사 | 보는 방향 쪽으로 박수를 칩니다 |

- 적이 떨어뜨린 경험치를 모아 레벨이 오르면 강화 카드 3장 중 하나를 고릅니다. 레벨 7과 14에는 속성(화염, 번개, 산성, 냉기, 암흑)을 붙입니다.
- 1분마다 특수 효과 두루마리를 고릅니다(최대 2개).
- 30초마다 웨이브가 바뀌며 적이 많아지고, 빨라지고, 단단해집니다. 박쥐는 빠르고, 유령은 줄지어 맵을 쓸고 지나갑니다.
- 최대한 오래 버티는 게 목표이고, 30분을 버티면 생존 성공입니다.

[Releases](https://github.com/shinkm1104/survivor-rl-qa/releases/latest)에서 Windows용 ZIP을 받아 `SurvivorLab.exe`로 직접 해볼 수 있습니다. 조작은 WASD로 이동, 1·2·3으로 카드 선택, Space로 일시 정지입니다.
