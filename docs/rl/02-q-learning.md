# 2단계: 표 기반 Q-learning (이동 정책)

> 648개 상태 표로 이동을 학습했다. 무작위·정지·도주 봇은 대부분 넘었지만, 사람이 짠 회피·사냥 봇에는 크게 못 미쳤다. 가장 가까운 적 하나만 보는 표 관측의 한계로 보이며, 3단계 DQN에서 관측 30개 전체를 쓰는 이유가 된다.

## 설정

[1단계 설계](01-environment.md) 9절의 시작 설정을 그대로 썼다. 바꾼 것은 학습 판 수 비교 실험(20,000판) 하나다.

| 항목 | 값 |
|---|---|
| 상태 | 가장 가까운 적 방향 8 × 거리 3 × 벽 9 × 체력 3 = 648 |
| 행동 | 정지 + 8방향 |
| 보상 | 생존 +0.01/step, 사망 −1. 5분 도달은 중단으로 보고 다음 상태 가치를 이어서 계산 |
| 학습률 α / 할인율 γ | 0.1 / 0.99 |
| 탐색률 ε | 1.0 → 0.05, 학습 판 수의 앞 50% 동안 선형 감소 |
| 학습 판 수 | 마법사당 2,000판 (비교 실험 20,000판) |
| 동시 진행 | 한 Unity 프로세스에 16판, 마법사 4명은 프로세스 4개로 동시에 |
| 훈련 시드 | 0 ~ 899,999 무작위, 평가 시드(900,000~900,039)와 분리 |
| 레벨업 카드 | 규칙 기반 선택 고정 |

실행:

```
cd python
uv run python train_q.py --class 0 --episodes 2000
uv run python eval.py --agents still random flee kite q --q-dir ../results/q-learning --out ../results/step2-q-learning
```

## 결과

평균 생존 시간 / 5분 완주율, 마법사당 평가 시드 40판.

| 에이전트 | 마탄술사 | 파동술사 | 바위술사 | 박수술사 |
|---|---:|---:|---:|---:|
| 정지 봇 | 294초 / 95% | 78초 / 0% | 12초 / 0% | 28초 / 0% |
| 무작위 봇 | 276초 / 88% | 88초 / 0% | 31초 / 0% | 19초 / 0% |
| 도주 봇 | 299초 / 98% | 89초 / 0% | 36초 / 0% | 49초 / 0% |
| 회피·사냥 봇 | 270초 / 78% | **263초 / 45%** | **165초 / 2%** | **141초 / 5%** |
| Q-learning 2,000판 | **300초 / 100%** | 137초 / 0% | 43초 / 0% | 35초 / 0% |
| Q-learning 20,000판 | (학습 안 함) | 161초 / 0% | 52초 / 0% | 54초 / 0% |

학습 시간(이 PC, 12코어): 2,000판은 마법사당 23초~6분, 20,000판은 4~11분. 판이 길수록(오래 살수록) 오래 걸린다.

방문한 상태 수(648개 중): 2,000판 417~581개, 20,000판 595~638개.

원본: [`results/step1-baselines`](../../results/step1-baselines), [`results/step2-q-learning`](../../results/step2-q-learning), [`results/step2-q-learning-20k`](../../results/step2-q-learning-20k). 학습 곡선은 `results/q-learning*/curve_class*.csv`.

## 해석

1. **마탄술사는 5분 판에서 변별력이 없다.** 정지 봇도 95% 완주한다. Q-learning 100%는 의미 있는 차이가 아니다. 1단계 완료 기준("정지 봇 완주율이 높으면 밸런스부터 고친다")에 걸린다. 아래 '마탄술사 문제' 참고.
2. **나머지 세 명은 학습이 된다.** 무작위·정지 봇보다 낫고, 학습 판 수를 10배로 늘리면 더 오래 산다(파동술사 137→161초, 바위술사 43→52초, 박수술사 35→54초).
3. **그래도 회피·사냥 봇에 크게 못 미친다.** 판 수를 늘려 얻은 이득이 작아서, 학습량보다 표현력이 병목으로 보인다. 회피·사냥 봇은 주변 적 여러 마리의 위치와 경험치 구슬 위치를 쓰는데, 표 관측은 가장 가까운 적 하나만 본다. 경험치 구슬을 모르니 레벨을 올리기 어렵다. (가설. 3단계에서 관측 30개 전체를 쓰는 DQN으로 확인한다.)
4. 바위술사·박수술사는 회피·사냥 봇조차 5분 완주율이 2~5%다. 에이전트 문제와 별개로 두 마법사가 약할 가능성이 있다. 6단계 자동 QA에서 다룰 후보다.

## 마탄술사 문제

5분 판이라서 생긴 현상인지 보려고 판 길이를 게임 최대치인 30분으로 늘려 다시 쟀다([`results/step2-matan-30min`](../../results/step2-matan-30min)).

| 봇 (30분 판) | 평균 생존 | 30분 완주율 | 받은 피해 평균 |
|---|---:|---:|---:|
| 정지 | 1,719초 | 95% | 86 |
| 도주 | 1,762초 | 98% | 45 |
| 회피·사냥 | 1,433초 | 78% | 196 |

- **정지 봇은 30분 판에서도 95%가 끝까지 버틴다.** 받은 피해 평균이 5분 판과 똑같이 86이다. 처음 5분을 넘기면 그 뒤로는 피해를 전혀 받지 않는다는 뜻이다.
- 판 길이 문제가 아니라 실제 밸런스 문제다. 마탄술사는 가장 가까운 적을 자동으로 쏘기 때문에, 공격 속도가 적 생성 속도를 앞서면 적이 플레이어에게 닿기 전에 모두 쓰러진다(가설. 웨이브 강화는 270초에 끝나고 그 뒤로 더 세지지 않는다).
- 오히려 움직이는 봇(회피·사냥)이 더 자주 죽는다. 이 마법사는 움직일 이유가 없다.
- 이 결과는 환경을 만들고 처음 돌린 평가에서 나온 **첫 자동 QA 발견**이다. 기존 버전의 984판 측정에서도 같은 유형("가만히 있어도 이기는 마법사")이 나왔는데, 마법사 개편 후에도 남아 있다.

**결정이 필요한 것**: 마탄술사를 고칠지(예: 270초 이후에도 웨이브가 계속 세지게), 고친다면 언제 고칠지. 고치기 전까지 마탄술사는 학습 결과 비교에서 빼고 본다.
