# 2단계: 표 기반 Q-learning (이동 정책)

> 648개 상태 표로 이동을 학습했다. 첫 평가에서 파동술사가 가만히 있어도 이기는 문제를 찾아 반경과 공격 속도를 낮췄다. 무작위·정지·도주 봇은 대부분 넘었지만, 사람이 짠 회피·사냥 봇에는 크게 못 미쳤다. 가장 가까운 적 하나만 보는 표 관측의 한계로 보이며, 3단계 DQN에서 관측 30개 전체를 쓰는 이유가 된다.

## 설정

[1단계 설계](01-environment.md) 9절의 시작 설정을 그대로 썼다. 바꾼 것은 학습 판 수 비교 실험(20,000판) 하나다.

| 항목 | 값 |
|---|---|
| 상태 | 가장 가까운 적 방향 8 × 거리 3 × 벽 9 × 체력 3 = 648 |
| 행동 | 정지 + 8방향 |
| 보상 | 생존 +0.01/step, 사망 −1. 5분 도달은 중단으로 보고 다음 상태 가치를 이어서 계산 |
| 학습률 α / 할인율 γ | 0.1 / 0.99 |
| 탐색률 ε | 1.0 → 0.05, 학습 판 수의 앞 50% 동안 선형 감소 |
| 학습 판 수 | 마법사당 2,000판 (비교 실험 20,000판) |
| 동시 진행 | 한 Unity 프로세스에 16판, 마법사 4명은 프로세스 4개로 동시에 |
| 훈련 시드 | 0 \~ 899,999 무작위, 평가 시드(900,000\~900,039)와 분리 |
| 레벨업 카드 | 규칙 기반 선택 고정 |

실행:

```
cd python
uv run python train_q.py --class 0 --episodes 2000
uv run python eval.py --agents still random flee kite q --q-dir ../results/q-learning --out ../results/step2-q-learning
```

### 파동술사 수정 후 (반경 2.5→2.0, 공격 속도 ×0.8)

파동술사만 바꿨으므로 Q-learning은 파동술사만 2,000판 다시 학습했다(1분). 나머지 세 명은 위와 같은 정책이다.

| 에이전트 | 파동술사 | 마탄술사 | 바위술사 | 박수술사 |
|---|---:|---:|---:|---:|
| 정지 봇 | 51초 / 5% | 78초 / 0% | 12초 / 0% | 28초 / 0% |
| 무작위 봇 | 40초 / 0% | 90초 / 0% | 31초 / 0% | 18초 / 0% |
| 도주 봇 | 139초 / **32%** | 89초 / 0% | 36초 / 0% | 49초 / 0% |
| 회피·사냥 봇 | **171초** / 22% | **263초 / 45%** | **165초 / 2%** | **141초 / 5%** |
| Q-learning 2,000판 | 116초 / 20% | 137초 / 0% | 43초 / 0% | 35초 / 0% |

무작위 봇의 마탄술사·박수술사 수치가 1\~2초 다른 것은, 무작위 봇이 난수 하나를 모든 판이 나눠 쓰는데 파동술사 판이 일찍 끝나며 순서가 바뀌었기 때문이다. 밸런스 변화와는 무관하다.

원본: [`results/step1-baselines`](../../results/step1-baselines), [`results/step2-q-learning`](../../results/step2-q-learning), [`results/step2-pulse-nerf`](../../results/step2-pulse-nerf)(수정 후), [`results/step2-q-learning-20k`](../../results/step2-q-learning-20k). 학습 곡선은 `results/q-learning*/curve_class*.csv`.

## 해석

1. **처음 수치의 파동술사는 5분 판에서 변별력이 없었다.** 정지 봇도 95% 완주해서 Q-learning 100%는 의미가 없었다. 1단계 완료 기준("정지 봇 완주율이 높으면 밸런스부터 고친다")에 걸려 수치를 고쳤다. 수정 후 Q-learning은 116초 / 20%로, 회피·사냥 봇(171초 / 22%)보다 평균 생존은 짧지만 완주율은 비슷하다. 아래 '파동술사 문제' 참고.
2. **나머지 세 명은 학습이 된다.** 무작위·정지 봇보다 낫고, 학습 판 수를 10배로 늘리면 더 오래 산다(마탄술사 137→161초, 바위술사 43→52초, 박수술사 35→54초).
3. **그래도 회피·사냥 봇에 크게 못 미친다.** 판 수를 늘려 얻은 이득이 작아서, 학습량보다 표현력이 병목으로 보인다. 회피·사냥 봇은 주변 적 여러 마리의 위치와 경험치 구슬 위치를 쓰는데, 표 관측은 가장 가까운 적 하나만 본다. 경험치 구슬을 모르니 레벨을 올리기 어렵다. (가설. 3단계에서 관측 30개 전체를 쓰는 DQN으로 확인한다.)
4. 바위술사·박수술사는 회피·사냥 봇조차 5분 완주율이 2\~5%다. 에이전트 문제와 별개로 두 마법사가 약할 가능성이 있다. 6단계 자동 QA에서 다룰 후보다.

## 파동술사 문제

5분 판이라서 생긴 현상인지 보려고 판 길이를 게임 최대치인 30분으로 늘려 다시 쟀다([`results/step2-pulse-30min`](../../results/step2-pulse-30min)).

| 봇 (30분 판) | 평균 생존 | 30분 완주율 | 받은 피해 평균 |
|---|---:|---:|---:|
| 정지 | 1,719초 | 95% | 86 |
| 도주 | 1,762초 | 98% | 45 |
| 회피·사냥 | 1,433초 | 78% | 196 |

- **정지 봇은 30분 판에서도 95%가 끝까지 버틴다.** 받은 피해 평균이 5분 판과 똑같이 86이다. 처음 5분을 넘기면 그 뒤로는 피해를 전혀 받지 않는다는 뜻이다.
- 판 길이 문제가 아니라 실제 밸런스 문제다. 파동술사는 내 주위 원 안의 적을 전부 때리기 때문에, 다가오는 적이 몸에 닿기 전에 맞는다. 화력이 적 생성 속도를 앞서면 적이 닿기 전에 모두 쓰러진다(가설. 웨이브 강화는 270초에 끝나고 그 뒤로 더 세지지 않는다).
- 오히려 움직이는 봇(회피·사냥)이 더 자주 죽는다. 이 마법사는 움직일 이유가 없다.
- 이 결과는 환경을 만들고 처음 돌린 평가에서 나온 **첫 자동 QA 발견**이다. 기존 버전의 984판 측정에서도 같은 유형("가만히 있어도 이기는 마법사")이 나왔는데, 마법사 개편 후에도 남아 있다.

**결정**: 파동술사를 고친다(2026-11-24). 아래 수치 실험을 보고 반경 2.5→2.0, 공격 속도 ×0.8(초당 1.80→1.44회)로 정했다. 피해 4.4는 그대로.

### 이름 정정 (2026-11-24)

처음 기록할 때 Python의 마법사 이름 목록이 게임 순서와 달라 0번(파동술사)과 1번(마탄술사)이 뒤바뀌어 있었다. 이 문서와 `results/*/summary.md`의 표는 라벨만 고쳤고 수치는 그대로다. `games.csv`의 `class` 값은 게임 순서(0 파동술사, 1 마탄술사, 2 바위술사, 3 박수술사)다. 이전 버전(984판 측정)의 공명술사가 지금의 파동술사이고, 그때도 웨이브 도입 뒤 정지 봇 87.5%로 같은 문제가 남아 있었다.

### 파동술사 수치 실험

빌드 폴더의 `balance.json`만 잠시 바꿔 정지·무작위·회피+사냥 봇을 다시 쟀다(평가 시드 40판, 5분). 평균 생존 / 5분 완주율. 게임 수치(`Assets/StreamingAssets/balance.json`)는 바꾸지 않았다.

| 변경 | 정지 봇 | 무작위 봇 | 회피·사냥 봇 |
|---|---:|---:|---:|
| 현재 (피해 4.4, 초당 1.8회, 반경 2.5) | 294초 / 95% | 276초 / 88% | 271초 / 78% |
| 공격 속도 ×0.8 | 215초 / 65% | 175초 / 48% | 211초 / 40% |
| 공격 속도 ×0.65 | 82초 / 18% | 61초 / 8% | 161초 / 13% |
| 피해 3.5 | 275초 / 90% | 180초 / 45% | 195초 / 30% |
| 피해 3.0 | 144초 / 40% | 106초 / 23% | 153초 / 13% |
| 반경 2.0 | 216초 / 68% | 126초 / 28% | 189초 / 30% |
| 반경 1.6 | 47초 / 3% | 48초 / 3% | 140초 / 8% |

- 반경 1.6을 빼면 어느 수치를 내려도 정지 봇의 완주율이 회피·사냥 봇보다 높다. 수치를 낮추면 전체가 약해질 뿐, "서 있는 게 낫다"는 관계는 대체로 그대로다. 반경 1.6처럼 아주 약하게 만들어야 뒤집히는데, 그때는 회피·사냥 봇도 8%밖에 완주하지 못한다.
- 정지 봇은 적이 몸 주위로 모이게 둬서 한 번에 많이 잡고 빨리 레벨을 올린다(현재 수치에서 처치 2,799 vs 1,255). 피하면 파동 안에 들어오는 적이 줄어 성장이 늦다. 수치보다 구조(적이 모일수록 유리한 범위 공격)가 원인으로 보인다.
- 결과가 문턱처럼 갈린다. 공격 속도 ×0.8과 ×0.65 사이, 반경 2.0과 1.6 사이에서 완주율이 급히 떨어진다. 일정 레벨을 넘기면 더 이상 위협이 없는 눈덩이 구조로 보인다(가설. 카드 구성 분석으로 확인 필요).

반경 2.0과 공격 속도 ×0.8을 같이 적용하고 피해도 낮춰 봤다.

| 반경 2.0, 공격 속도 ×0.8에 피해를 | 정지 봇 | 회피·사냥 봇 |
|---|---:|---:|
| 4.4 그대로 | 51초 / 5% | **171초 / 23%** |
| 4.0 | 42초 / 3% | 163초 / 18% |
| 3.5 | 27초 / 0% | 134초 / 3% |

- 반경과 공격 속도를 같이 낮추면 처음으로 정지 봇이 회피·사냥 봇보다 불리해진다. 피해까지 낮추면 회피·사냥 봇도 거의 완주하지 못한다. 그래서 피해 4.4 그대로를 골랐다.

### 수정 후 남은 문제: 도망이 싸움보다 낫다

- 수정 후 파동술사는 도주 봇(32%)이 회피·사냥 봇(22%)보다 5분 완주율이 높다. 평균 생존은 회피·사냥 봇이 길다(171초 vs 139초).
- 회피·사냥 봇의 처치 수가 1,255에서 86으로 줄었다. 싸워서 성장하기보다 피해서 버티는 마법사가 됐다는 뜻이다. 이전 버전 측정의 "도망만 다니면 이긴다" 문제와 같은 성격이다.
- 카드 구성 분석(빌드 필요)과 함께 다음 밸런스 후보로 둔다.
